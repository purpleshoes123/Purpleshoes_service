JSX 포맷은 같은 표시 공백을 명시적 공백 노드로 나눌 수 있어 단순 AST 위치 비교 대신 지정 포맷 결과 대조와 컴파일을 함께 확인했습니다. 모든 사용자 시나리오의 실기기 검증을 대신하는 기록은 아닙니다.

Windows 격리 환경의 임시 폴더 권한·Black 로컬 IPC 제한은 실행 환경을 조정해 검증했습니다. 업무 코드 기대값을 바꿔 우회하지 않았습니다.

## 리뷰와 적용

기능 지도 → 경로 이동표 → 공백 차이를 숨긴 코드 diff → 형식 도구·CI 순으로 확인합니다. DB·가격·권한·쿠폰·메일 정책·UI 문구의 기능 변경은 포함하지 않습니다.

작업 브랜치 PR은 검증만 실행합니다. main merge 후 변경된 서버·테마·앱이 운영 배포 대상이 됩니다. 배포 후 가이드·투어·관리자·메일 작업자·관련 API를 운영 매뉴얼에 따라 확인합니다. 실제 결제·환불·메일 발송·운영 데이터 변경 테스트는 이번 로컬 검증에서 실행하지 않았습니다.
