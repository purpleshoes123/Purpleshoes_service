# 회원가입 감사 · 통합안 UI — 2026-10-29

사용자 제공 `시안_비교안내.html`의 05번 우측 시안을 기준으로 회원가입 감사 페이지 본문을 변경했습니다. `page.thankyou.json`과 `page.thank-you.json` 모두 같은 섹션과 문구를 사용합니다.

## 구성과 가격

가입 완료·무료 Starter Kit 안내 → Kit 제목과 실제 콘텐츠 화면 3개·가격 카드 → 편익 3칸 → 제작자 안내 → 하단 CTA 순서입니다. 모바일과 태블릿에서는 가격 카드를 먼저 보여줍니다.

사용자의 추가 지시에 따라 표시 가격은 **USD 75**, 취소선 정가는 **USD 150**으로 고정했습니다. 회원·구매·쿠폰 상태에 따라 가격이나 CTA를 바꾸지 않습니다. 본문에서 쿠폰·카탈로그·구매 자격 API를 호출하지 않으며, 발급 후 24시간 안내는 정적 문구입니다. 카운트다운은 표시하지 않습니다.

- 무료 CTA: `Open My Free Starter Kit` → `/pages/starter-kit-viewer`
- 가격 카드·하단 CTA: `View My Korea Guide Kit Offer` → `/pages/guide-plans#member-purchase`

화면 표시만 변경하며 실제 쿠폰 발급, 결제 가격 계산, 구매 자격 정책은 기존 코드를 유지합니다. 기존 고객 환영 localStorage 표식도 유지합니다. 구형 공유·추가 할인 UI는 본문에서 제외하되 공유 쿠폰 관련 공용 스크립트나 백엔드는 수정하지 않았습니다.

## 이미지와 범위

전달받은 `개발자_원본자산` 폴더의 Purple Map, Korean BBQ 가이드북, Jeju 동영상 실제 화면 PNG를 테마 자산에 그대로 포함했습니다. 이미지 비율과 지도 출처 표기를 보존하며 생성 이미지로 대체하거나 화면을 자르지 않았습니다.

상단 카테고리·로고·로그인 메뉴, 푸터, 공통 레이아웃과 다른 페이지의 공용 `thank-you-offer.js`, 앱 백엔드는 수정하지 않았습니다. 새 스타일은 `.sgty`와 그 하위 클래스에 한정했습니다.

## 검증과 적용 상태

- LiquidJS로 비회원·미결제 회원·결제 회원 본문 및 CTA가 동일함을 확인했습니다.
- Codex 내장 브라우저에서 1280px PC, 390px·320px 모바일, 768px 태블릿을 확인했습니다. 이미지 로드, 링크, 고정 가격과 가로 넘침 여부를 확인했습니다.
- Shopify Theme Check로 변경 테마 파일 8개를 검사했습니다. 문서 최신본 네트워크 접근이 제한되어 검사 도구의 번들 문서를 사용했습니다.
- 헤더·푸터·레이아웃·백엔드·기존 공용 스크립트에 Git diff가 없음을 확인했습니다.

로컬 소스 수정만 완료했습니다. 운영 배포·커밋·푸시는 실행하지 않았습니다. 실제 계정의 가입·결제는 실행하지 않았습니다.
