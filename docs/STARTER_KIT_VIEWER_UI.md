# 무료 Starter Kit 뷰어 UI 변경 — 2026-10-29

대상: `/pages/starter-kit-viewer` 본문. 사용자 제공 `시안_비교안내.html`의 03번 우측 v4와 확정 문구를 기준으로 구현했습니다.

## 범위

공통 상단 카테고리·로고·로그인 메뉴와 푸터, 공통 레이아웃은 수정하지 않았습니다. 로컬 검토 HTML도 본문만 렌더링합니다.

본문 구성은 쌈 사진 hero → 무료 영상·가이드북 → 무료/유료 Kit 비교·선별 근거 → 퍼플맵 시연 → 하단 CTA 순서입니다. hero 사진은 메인페이지에서 이미 사용하는 실제 Shopify 이미지 `938207a5477970309a67488f9a0400dc.png`입니다. 생성 시안의 사진·작은 지도 글씨를 복사하지 않았습니다.

## 미디어

- 기존 무료 영상 URL을 유지했습니다. 브라우저에서 42:36 길이를 확인했으며 자동 재생하지 않습니다.
- 기존 무료 가이드북의 48개 페이지 이미지로 PC·모바일 공통 리더를 표시합니다. 페이지 넘김·페이지 수·전체화면·닫기·Escape 복귀를 제공합니다. 기존 PDF URL 설정과 원본은 유지하며, PDF 플러그인이 없는 브라우저에서도 페이지를 열람할 수 있습니다.
- 전달 폴더에 실제 `퍼플맵 소개 영상.mp4`가 있어 문서의 과거 ‘수령 대기’ 상태 대신 이 파일을 사용했습니다. 원본은 56.52초, 4114×2160 HEVC입니다. 화면을 자르거나 늘리지 않고 1920×1080 프레임에 여백을 넣어 H.264 MP4로 변환했습니다. 웹용 파일은 16,820,692바이트입니다.
- 포스터는 실제 동영상의 3초 시점에서 추출했습니다. 중앙 버튼 클릭 시 같은 16:9 프레임에서 재생되며 자동 재생하지 않습니다. 재생 시작 후 중앙 버튼은 숨겨지고 기본 영상 조작을 사용할 수 있습니다.
- 웹용 MP4와 포스터는 테마 자산에 포함했습니다. 필요하면 Theme Editor의 퍼플맵 영상 URL로 대체할 수 있습니다.

## 검증

- LiquidJS로 비회원·미결제 회원·결제 회원을 각각 렌더링하고 본문 HTML 및 두 CTA가 동일함을 확인했습니다. 실제 고객 계정이나 주문 데이터는 생성하지 않았습니다.
- Codex 내장 브라우저에서 PC 1280px, 모바일 390px·320px, 태블릿 768px 배치를 확인했습니다. 모바일 비교 카드는 무료 다음 유료 순서이며 퍼플맵 설명 다음 영상이 배치됩니다.
- PC·모바일에서 가이드북 다음 페이지·전체화면·닫기 동작을 확인했습니다. PC에서는 Escape 복귀도 확인했습니다.
- PC·390px 모바일에서 실제 퍼플맵 영상 재생, 중앙 버튼 숨김, 기본 재생 조작을 확인했습니다.
- UTM이 두 CTA에 동일하게 보존되는지 확인했습니다.
- Shopify Theme Check: 변경 테마 파일 8개 통과. JavaScript 문법 및 `git diff --check` 통과.
- 공통 레이아웃·헤더·푸터의 Git diff가 없음을 확인했습니다. 상품 상세의 공개 접근 허용 설정은 기존 코드를 유지합니다.
